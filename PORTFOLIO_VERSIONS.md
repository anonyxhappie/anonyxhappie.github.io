# Portfolio Versions

This repository treats the portfolio as a versioned product. Major changes preserve the previous experience rather than overwriting it.

| Version | Status | Experience |
|---|---|---|
| `v1` | Archived | Earlier personal portfolio |
| `v2` | Archived | Physics-driven interactive portfolio |
| `v3` | Current | Professional engineering portfolio |

## Git model

- `master` is the current production portfolio.
- `v1` and `v2` are preserved historical branches.
- Future major redesigns should use `v4`, `v5`, etc.
- Smaller content, accessibility, responsive, and visual fixes remain within the current major version.

## Current v3

The current experience prioritizes selected engineering work over a repository dump. Projects link directly to their GitHub repositories, while the site communicates engineering focus, experience, technical interests, and an engineering thesis.
