# Portfolio Versions

This repository preserves major portfolio iterations as separate Git branches.

| Version | Status | Purpose |
|---|---|---|
| `v1` | Archived | Earlier personal portfolio experience. |
| `v2` | Archived | Interactive physics/newspaper portfolio. |
| `v3` | Current | Professional portfolio focused on engineering work, selected projects, experience, and verified project links. |

## Versioning policy

- Major redesigns or changes in portfolio positioning receive a new major version.
- Small content, accessibility, responsive, and visual fixes stay within the current major version.
- Historical branches are preserved rather than overwritten.
- The production Pages branch is promoted only after the current version is reviewed.
